# 한국 대학입시 정보 챗봇 서비스

한국 대학 입시에 대한 정보를 제공하는 AI 챗봇 서비스입니다.

## 주요 기능

### 대학입시 챗봇
- 📚 수능 및 내신 정보 제공
- 🏫 대학별 입시 요강 안내
- 📊 입시 전형 정보 (수시/정시)
- 💡 학생부종합전형 가이드
- 🎯 전공 선택 상담

### 📰 일일 뉴스 텔레그램 봇 (NEW!)
- 🤖 매일 원하는 시간에 자동으로 뉴스 검색
- 🧠 Claude AI가 뉴스를 요약하여 전달
- 📱 텔레그램으로 간편하게 수신
- ⚙️ 원하는 주제 키워드 설정 가능

> 자세한 설정 방법은 [NEWS_BOT_GUIDE.md](./NEWS_BOT_GUIDE.md)를 참조하세요.

## 기술 스택

- **Backend**: Node.js, Express
- **Frontend**: React
- **AI**: 자연어 처리 기반 챗봇

## 시작하기

### 설치

```bash
npm install
cd client && npm install
```

### 실행

```bash
# 백엔드 서버 실행
npm start

# 개발 모드 (백엔드 + 프론트엔드 동시 실행)
npm run dev:all
```

## API 엔드포인트

- `POST /api/chat` - 챗봇 메시지 전송
- `GET /api/universities` - 대학 목록 조회
- `GET /api/admissions/info` - 입시 정보 조회

## 제공 정보

### 1. 수능 관련
- 수능 일정 및 시험 과목
- 영역별 학습 방법
- 등급 및 표준점수 계산

### 2. 내신 관련
- 내신 등급 계산 방법
- 학생부 관리 팁
- 비교과 활동 가이드

### 3. 대학별 정보
- SKY (서울대, 고려대, 연세대)
- 주요 대학 입시 요강
- 학과별 경쟁률 및 커트라인

### 4. 전형 정보
- 수시 전형 (학생부종합, 학생부교과, 논술 등)
- 정시 전형 (가/나/다군)
- 특별 전형 정보
