# News Production Harness

AI 기반 뉴스 기사 자동 생산 파이프라인입니다.

4단계 자동화된 워크플로우를 통해 발제부터 최종 편집까지 완성도 높은 뉴스 기사를 생산합니다.

## 파이프라인

```
주제 입력 → 발제 → 취재/작성 → 팩트체크 → 데스킹 → 최종 기사
```

| 단계 | 역할 | 설명 |
|------|------|------|
| Stage 1: 발제 | 15년차 기자 | 뉴스 가치 분석, 취재 계획, 기사 구성안 |
| Stage 2: 작성 | 15년차 기자 | 웹 검색 취재, 출처 기반 기사 작성 |
| Stage 3: 팩트체크 | 20년차 팩트 체커 | 교차 검증, 신뢰도 등급 판정 |
| Stage 4: 데스킹 | 20년차 편집부장 | 제목/리드/본문 교정, 게재 판정 |

## 사용법

### 전체 파이프라인 실행

```
/news-full [주제]
```

### 단계별 실행

```
/news-pitch [주제]        # 발제
/news-write [파일경로]     # 기사 작성
/news-factcheck [파일경로] # 팩트체크
/news-desk [파일경로]      # 데스킹
```

## 디렉토리 구조

```
.
├── README.md
├── news-harness/
│   ├── CLAUDE.md          # 파이프라인 실행 규칙
│   ├── prompts/           # 단계별 프롬프트
│   │   ├── 01-pitch.md
│   │   ├── 02-write.md
│   │   ├── 03-factcheck.md
│   │   └── 04-desking.md
│   ├── sources/           # 참고 자료 (선택)
│   └── output/            # 생성된 기사 및 보고서
└── .claude/
    └── skills/            # 슬래시 커맨드 스킬 파일
        ├── news-pitch/
        ├── news-write/
        ├── news-factcheck/
        ├── news-desk/
        └── news-full/
```

## 품질 기준

- 팩트체크 신뢰도 **B등급 이상** 필요
- 데스킹 총평 **평균 3.5점 이상** 필요
- 미달 시 해당 단계부터 자동 재실행

## 핵심 원칙

- **정보 유형 구분**: 공식 발표 / 복수 매체 보도 / 애널리스트 추정 / 루머를 명확히 구분하여 서술
- **교차 검증**: 모든 사실은 최소 2개 독립 출처로 확인
- **투명한 출처**: 기사 내 모든 주장에 출처 명시

## 참고 자료 활용

`news-harness/sources/` 디렉토리에 보도자료, 통계, 인터뷰 녹취 등을 넣어두면 Stage 2에서 자동 참조됩니다.
