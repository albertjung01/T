# 뉴스 기사 자동 생산 하네스

AI 기반 뉴스 기사 자동 생산 파이프라인입니다. 4단계(발제 → 취재/작성 → 팩트체크 → 데스킹)를 거쳐 완성도 높은 뉴스 기사를 생산합니다.

## 파이프라인 구조

```
주제 입력
    │
    ▼
┌─────────────────────────────────┐
│ Stage 1: 기사 발제               │
│ 역할: 15년차 베테랑 기자          │
│ - 뉴스 가치 분석                 │
│ - 취재 계획 수립                 │
│ - 기사 구성안 작성               │
└─────────────┬───────────────────┘
              │
              ▼
┌─────────────────────────────────┐
│ Stage 2: 취재 및 기사 작성        │
│ 역할: 15년차 베테랑 기자          │
│ - 웹 검색 + 파일 자료 조사        │
│ - 취재원 인용 포함 기사 작성      │
│ - 출처 목록 정리                 │
└─────────────┬───────────────────┘
              │
              ▼
┌─────────────────────────────────┐
│ Stage 3: 팩트 체크               │
│ 역할: 20년차 베테랑 팩트 체커     │
│ - 모든 사실관계 추출 및 검증      │
│ - 교차 검증 (2개+ 독립 출처)     │
│ - 신뢰도 등급 판정               │
│ - 오류 발견 시 기사 직접 수정     │
└─────────────┬───────────────────┘
              │
              ▼
┌─────────────────────────────────┐
│ Stage 4: 데스킹                  │
│ 역할: 20년차 베테랑 편집부장       │
│ - 제목/리드/본문 구조 검토        │
│ - 문장/문체 교정                 │
│ - 법적/윤리적 검토               │
│ - 최종 기사 완성 + 게재 판정      │
└─────────────┬───────────────────┘
              │
              ▼
        최종 기사 출력
```

## 디렉토리 구조

```
news-harness/
├── CLAUDE.md              # 하네스 실행 설명서 (Claude Code용)
├── README.md              # 이 파일
├── prompts/               # 단계별 프롬프트
│   ├── 01-pitch.md        # 기사 발제 프롬프트
│   ├── 02-write.md        # 취재/작성 프롬프트
│   ├── 03-factcheck.md    # 팩트체크 프롬프트
│   └── 04-desking.md      # 데스킹 프롬프트
├── sources/               # 참고 자료 (보도자료, 통계 등)
│   └── .gitkeep
└── output/                # 생성된 기사 및 보고서
    └── .gitkeep
```

## 사용 방법

### 1. 기본 실행

Claude Code에서 `news-harness/` 디렉토리를 작업 디렉토리로 설정한 후, 기사 주제를 입력하세요:

```
"AI 규제 동향에 대한 뉴스 기사를 작성해줘"
```

Claude가 CLAUDE.md의 지시에 따라 4단계를 순차적으로 실행합니다.

### 2. 참고 자료 활용

기사 작성에 활용할 자료가 있으면 `sources/` 디렉토리에 넣어두세요:

```
sources/
├── 보도자료-AI규제법안.md
├── 통계-AI산업현황.csv
└── 인터뷰-전문가의견.txt
```

Stage 2에서 자동으로 참조됩니다.

### 3. 출력 파일

각 단계 완료 후 `output/` 디렉토리에 결과 파일이 생성됩니다:

| 파일 | 설명 |
|------|------|
| `01-pitch-*.md` | 기사 발제안 |
| `02-article-*.md` | 기사 초안 (팩트체크 후 수정됨) |
| `03-factcheck-*.md` | 팩트체크 보고서 |
| `04-final-*.md` | 최종 기사 |
| `04-desking-report-*.md` | 데스킹 리포트 |

### 4. 품질 기준

- 팩트체크 신뢰도 **B등급 이상** 필요
- 데스킹 총평 **평균 3.5점 이상** 필요
- 미달 시 해당 단계부터 재실행

## 커스터마이징

### 프롬프트 수정

`prompts/` 디렉토리의 각 파일을 수정하여 기사 스타일, 검증 기준 등을 조정할 수 있습니다.

### 역할 변경

각 프롬프트 파일의 "역할" 섹션을 수정하여 페르소나를 변경할 수 있습니다.

### 기사 유형 확장

`prompts/02-write.md`의 기사 구조 섹션을 수정하여 새로운 기사 유형(사설, 피처, 인포그래픽 등)을 추가할 수 있습니다.
