# 뉴스 기사 자동 생산 하네스 (News Article Production Harness)

## 개요

이 하네스는 뉴스 기사를 4단계 파이프라인으로 자동 생산합니다.
각 단계는 전문 역할을 가진 에이전트가 수행하며, 이전 단계의 출력을 입력으로 받아 순차적으로 실행됩니다.

## 파이프라인 구조

```
[주제 입력] → Stage 1: 발제 → Stage 2: 취재/작성 → Stage 3: 팩트체크 → Stage 4: 데스킹 → [최종 기사]
```

## 실행 방법

사용자가 뉴스 기사 주제를 제시하면 다음 4단계를 **순차적으로** 실행하세요.

### Stage 1: 기사 발제 (Story Pitching)
- **역할**: 15년차 베테랑 기자
- **프롬프트**: `prompts/01-pitch.md`
- **입력**: 사용자가 제시한 주제/이슈
- **출력**: `output/01-pitch-[주제요약].md`
- **도구**: WebSearch (트렌드 파악용)

### Stage 2: 취재 및 기사 작성 (Research & Writing)
- **역할**: 15년차 베테랑 기자
- **프롬프트**: `prompts/02-write.md`
- **입력**: Stage 1의 발제안
- **출력**: `output/02-article-[주제요약].md`
- **도구**: WebSearch (취재), Read (파일 참조), Glob (자료 탐색)

### Stage 3: 팩트 체크 (Fact Checking)
- **역할**: 20년차 베테랑 팩트 체커
- **프롬프트**: `prompts/03-factcheck.md`
- **입력**: Stage 2의 기사 원문
- **출력**: `output/03-factcheck-[주제요약].md` + 기사 원문 수정
- **도구**: WebSearch (교차 검증), Read (기사 원문)

### Stage 4: 데스킹 (Desking / Editorial Review)
- **역할**: 20년차 베테랑 데스크(편집부장)
- **프롬프트**: `prompts/04-desking.md`
- **입력**: 수정된 기사 + 팩트체크 보고서
- **출력**: `output/04-final-[주제요약].md` + `output/04-desking-report-[주제요약].md`
- **도구**: Read (기사 및 팩트체크 보고서)

## 실행 규칙

1. **순차 실행**: 반드시 Stage 1 → 2 → 3 → 4 순서로 실행
2. **역할 분리**: 각 단계에서 해당 역할의 프롬프트를 참조하여 역할에 맞게 수행
3. **파일 기반 전달**: 각 단계의 출력 파일이 다음 단계의 입력이 됨
4. **중간 확인**: 각 단계 완료 후 사용자에게 요약 보고하고 다음 단계 진행 여부 확인
5. **출력 보존**: 모든 단계의 출력 파일을 `output/` 디렉토리에 보존

## 주제요약 네이밍 규칙

파일명의 `[주제요약]` 부분은 다음 규칙을 따릅니다:
- 한글 또는 영문 소문자 사용
- 공백 대신 하이픈(-) 사용
- 최대 30자 이내
- 예: `ai-규제-동향`, `부동산-정책-변화`, `기후변화-대응`

## 품질 기준

- 팩트체크 신뢰도 등급 B 이상이어야 게재 가능
- 데스킹 총평 평균 3.5점 이상이어야 게재 가능
- 위 기준 미달 시 해당 단계부터 재실행

## sources 디렉토리

`sources/` 디렉토리에 기사 작성에 필요한 참고 자료를 미리 넣어두면,
Stage 2에서 자동으로 참조합니다.
- 보도자료, 통계 데이터, 인터뷰 녹취록 등
- 파일 형식: `.md`, `.txt`, `.csv`, `.json`
